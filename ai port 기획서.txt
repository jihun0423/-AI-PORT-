기획서: 스마트패스와 기존 서비스 통합을 통한 여객 편의성 증대

1. 개요
 - 목표: 스마트패스 서비스의 이용률을 높이고, 여객들의 공항 이용 편의성을 증대시키기 위한 스마트패스와 기존 서비스들의 통합 및 개선.
 - 배경: 현재 스마트패스의 이용률은 약 8%로 매우 낮고, 공항 내 혼잡도와 대기 시간이 높음. 이를 해결하기 위해 스마트패스의 활용도를 높여 공항 효율성을 개선하고, 여객의 편리한 이용을 도모.
 - 기술적 목표: 최신 AI 기술 및 데이터베이스를 활용하여 서비스 통합을 최적화하고 실시간으로 여객 편의성을 증대시킬 수 있는 시스템 구축.


2. 문제점 분석
 - 스마트패스 서비스의 기능 부족: 스마트패스 앱은 얼굴 인증, 여권 및 탑승권 등록, 백드롭 서비스 외에 실질적인 기능이 부족하여 여객들이 이용할 동기 부족.
 - 스마트패스 이용률 저조: 스마트패스의 이용률은 8%로 매우 낮음. 출국 수속을 효율화하고 공항 혼잡도를 줄일 수 있는 기회를 놓치고 있음.
 - 기존 서비스 간의 분리: 다양한 공항 서비스들이 서로 분리되어 있어, 여객들은 여러 앱과 시스템을 번갈아가며 사용해야 함.


3. 해결 방안 및 서비스 개선
 ○ 이지드롭 서비스와의 결합:
  - 목표 : 스마트패스를 활용해 수화물 위탁을 원활하게 하고, 이를 통해 스마트패스의 기능을 확장.
  - 기술 
   • AI 기반 리스크 예측 모델 : 수화물 위탁 시, 예상 도착시간, 리스크 및 위치 정보를 머신러닝 기반 AI 모델을 통해 예측하고 제공합니다. 예측 모델은 과거 데이터와 실시간 트래킹 정보를 기반으로 동작하며, 수화물 도착 예상시간을 정확히 예측합니다.
   • 데이터베이스: 수화물의 위치와 상태 정보를 추적하기 위해 실시간 위치 데이터베이스(NoSQL, Redis 등)을 활용하여 수화물의 현재 상태를 실시간으로 기록하고 업데이트합니다.

 ○ 실시간 얼굴 인식 기반 위치 추적 서비스:
  - 목표 : 공항 내 미탑승 승객의 위치를 추적하고 빠르게 탑승구로 안내하여 출국 수속을 원활하게 함.
  - 기술
   • 얼굴 인식 모델: 최신 딥러닝 기반 얼굴 인식 모델을 사용하여 승객의 얼굴을 실시간으로 인식합니다. 모델은 OpenCV와 dlib 라이브러리를 활용하며, TensorFlow나 PyTorch로 훈련된 모델을 사용합니다.
   • 실시간 CCTV 영상 분석: 공항에 설치된 CCTV 시스템을 활용하여 얼굴 인식 데이터를 실시간으로 분석합니다. CCTV에서 캡처된 얼굴 이미지는 실시간으로 서버로 전송되어 분석됩니다.
   • 데이터베이스: 얼굴 인식 데이터는 **관계형 데이터베이스(SQL, MySQL)**에 저장되고, 승객의 이동 경로와 상태 정보는 트래킹 데이터베이스(MongoDB 등)를 통해 실시간으로 관리됩니다.

 ○ 면세 쇼핑 서비스 연동:
  - 목표 : 스마트패스를 이용해 면세점에서 얼굴 인증만으로 간편하게 쇼핑하도록 지원하여 편리함을 증가.
  - 기술
   • 얼굴 인식 + 결제 시스템: 얼굴 인증을 통해 카드 정보 및 여권 정보를 인증하고, 면세점에서 쇼핑을 할 때는 Biometric Payment System을 적용하여, 얼굴 인증만으로 결제를 처리합니다.
   • 데이터베이스: 카드 정보와 여권 데이터는 암호화된 데이터베이스(MySQL, PostgreSQL)에 저장되며, 결제 처리 시스템과 연동되어 안전한 결제가 가능하도록 구성됩니다.
 ○ 서류 작성 및 음성 인식 서비스:
  - 목표 : 음성 인식을 통해 출국 및 입국 수속에 필요한 서류를 자동으로 작성하고, 수속 절차를 더 간편하게 만듬.
  - 기술
   • 음성 인식 기술: Google Speech-to-Text API나 DeepSpeech를 이용해 음성을 텍스트로 변환합니다. 이 텍스트 데이터를 시스템에서 자동으로 처리하여 서류를 생성합니다.
   • 자연어 처리(NLP): 서류에 필요한 데이터를 추출하고 자동으로 작성할 수 있도록 자연어 처리(NLP) 모델을 사용하여 음성으로 입력된 정보를 처리합니다.
   • 데이터베이스: 음성으로 작성된 서류 데이터는 DBMS(Oracle, PostgreSQL 등)에서 자동으로 관리되며, 서류 작성 진행 상황도 추적합니다.


4. 데이터베이스 구조 설계
 스마트패스 시스템에서 사용하는 데이터베이스는 크게 관계형 데이터베이스(SQL), 비관계형 데이터베이스(NoSQL), 캐시 데이터베이스(Redis) 등으로 구성됩니다. 각 데이터베이스는 다음과 같은 구조로 설계됩니다.

(1) 관계형 데이터베이스 (SQL)

- 사용 목적: 승객의 개인 정보, 예약 정보, 카드 정보, 여권 정보 등을 저장하고 관리하기 위해 사용.
- 주요 데이터:
승객 테이블 (Passenger):
passenger_id (Primary Key)
first_name
last_name
passport_number
email
phone_number
date_of_birth
registration_date

예약 테이블 (Reservation):
reservation_id (Primary Key)
passenger_id (Foreign Key)
flight_number
departure_time
arrival_time
seat_number

카드 정보 테이블 (Payment_Info):
payment_id (Primary Key)
passenger_id (Foreign Key)
card_number (암호화)
expiration_date
cardholder_name
billing_address

 - 연결: 승객 테이블, 예약 테이블, 카드 정보 테이블 간에 passenger_id를 외래 키로 사용하여 연결됩니다.


(2) 비관계형 데이터베이스 (NoSQL, MongoDB)

 - 사용 목적: 실시간 얼굴 인식 데이터, 수화물 위치 추적 데이터, CCTV 데이터 등 빠르게 변화하는 데이터를 관리.
 - 주요 데이터:
얼굴 인식 데이터 (Face_Recognition):
image_id (Unique)
passenger_id (Foreign Key)
image_data (이미지 데이터)
timestamp (얼굴 인식 시간)
location_data (위치 정보, GPS 좌표)

수화물 위치 데이터 (Baggage_Tracking):
baggage_id (Unique)
passenger_id (Foreign Key)
location_data (위치 정보, GPS 좌표)
status (현재 상태: 위탁, 이동 중, 도착 등)
estimated_arrival_time

실시간 승객 위치 데이터 (Passenger_Tracking):
passenger_id (Foreign Key)
location_data (위치 정보, GPS 좌표)
timestamp

 - 연결: 각 데이터는 승객 ID(passenger_id)를 외래 키로 사용하여 승객 관련 데이터를 추적하고 연결합니다.


(3) 캐시 데이터베이스 (Redis)

 - 사용 목적: 실시간 데이터 업데이트 및 빠른 응답을 위한 캐시 저장소로 사용.
 - 주요 데이터:
수화물 위치:
baggage:{baggage_id}:location → current_location
baggage:{baggage_id}:status → status
승객 얼굴 인식 상태:
face_recognition:{passenger_id} → recognized / not_recognized
 - 연결: Redis는 실시간 처리와 빠른 데이터 액세스를 위한 임시 저장소로 사용됩니다. 예를 들어, 승객 얼굴 인식 상태나 수화물 위치 데이터를 캐시하여 빠른 응답을 제공합니다.



5. 기술적 구현
 - 사용되는 기술
  • AI & 딥러닝 모델: TensorFlow, PyTorch, dlib (얼굴 인식), Keras (음성 인식)
  • 클라우드 컴퓨팅: AWS (EC2, S3, Lambda), Google Cloud AI (Cloud Vision API, Cloud Speech-to-Text API)
  • 데이터베이스: MySQL, PostgreSQL (관계형 데이터베이스), MongoDB (비관계형 데이터베이스), Redis (캐시)
  • 서버 및 배포: Docker, Kubernetes (컨테이너화 및 배포), Jenkins (CI/CD)
  • 프론트엔드: React Native (모바일 앱), React.js (웹 앱), Vue.js (UI 설계)
  • 보안: OAuth 2.0, JWT (인증 및 권한 관리), SSL/TLS (데이터 암호화)

 - 데이터 흐름 및 통합
  •스마트패스 앱: 여권 정보, 탑승권, 카드 정보를 클라우드 DB에 저장하고, 각 서비스(이지드롭, 얼굴 인식, 쇼핑 등)와 실시간으로 연동.
  • 서비스 간 데이터 통합: 모든 서비스는 중앙 데이터베이스(Microservices Architecture)로 통합되어 실시간 데이터 업데이트 및 모니터링이 가능하도록 설계됨.
  • AI 기반 예측: 수화물 위치 추적, 승객 얼굴 인식 등 실시간 AI 예측 모델은 데이터 파이프라인을 통해 실시간으로 예측 및 분석 결과를 제공.



6. 기대 효과
스마트패스 활성화: 다양한 서비스를 통합하여 스마트패스의 이용률을 증가시킬 수 있음.
공항 운영 효율성 향상: 출국 수속 시간 단축, 혼잡도 감소 및 공항의 원활한 운영을 도울 수 있음.
여객 편의성 증대: 간편한 쇼핑, 빠른 수속, 실시간 위치 추적 등을 통해 여객의 만족도를 대폭 향상시킬 수 있음.



7. 결론
스마트패스와 기존 서비스들의 통합을 통해 여객들이 스마트패스를 더욱 편리하게 사용하게 할 수 있으며, 공항 효율성을 개선하고 여객 편의성을 증대시킬 수 있음. 
최신 AI 기술과 클라우드 기반의 데이터베이스 관리 시스템을 사용하여, 실시간으로 여객들의 요구를 충족시키는 스마트 공항을 만들어 나갈 수 있습니다.
